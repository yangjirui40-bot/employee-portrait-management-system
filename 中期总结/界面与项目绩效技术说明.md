# UI设计与绩效排行功能总结报告

## 一、项目概述

本报告说明人员管理系统（PersonMIS）的UI界面设计以及项目管理模块中绩效排行功能的实现。通过现代化的UI设计和实用的绩效排行功能，提升了系统的用户体验和管理效率。

### 1.1 技术栈说明

- **前端框架**: Vue 3 + Element Plus
- **UI设计**: CSS3 + SCSS + Element Plus自定义主题
- **图表可视化**: ECharts
- **路由管理**: Vue Router
- **状态管理**: Pinia

### 1.2 完成的核心功能

1. **系统UI整体美化**: 统一界面风格，提升视觉体验
2. **主页设计与美化**: 优化布局结构，增强信息展示
3. **登录界面设计与美化**: 提升用户登录体验
4. **项目绩效排行功能**: 实现项目内员工绩效排名与可视化

export default {
  name: 'Home',
  data() {
    return {
      departmentCount: 0,
      staffCount: 0,
      departments: [],
      staffs: [],
      featuredStaffs: []
    }
  },
  computed: {
    userName() {
      try {
        const u = window.sessionStorage.getItem('user')
        if (!u) return '访客'
        const parsed = JSON.parse(u)
        return parsed && parsed.username ? parsed.username : parsed.name || '用户'
      } catch (e) {
        return '用户'
      }
    }
  },
  created() {
    this.loadData()
  },
  methods: {
    async loadData() {
      try {
        // 部门列表
        const deptResp = await this.$axios.get('/getDepartment')
        if (deptResp && deptResp.data) {
          const depts = Array.isArray(deptResp.data) ? deptResp.data : (deptResp.data.departs || [])
          this.departments = depts
          this.departmentCount = depts.length
        }

        // 员工列表
        let staffResp = await this.$axios.get('/getStaff').catch(() => null)
        if (!staffResp) {
          staffResp = await this.$axios.get('/getStaffByPage?currentPage=1&pageSize=1000').catch(() => null)
        }
        if (staffResp && staffResp.data) {
          let staffList = []
          if (Array.isArray(staffResp.data)) {
            staffList = staffResp.data
            this.staffCount = staffResp.data.length
          } else if (staffResp.data.staffs) {
            staffList = staffResp.data.staffs
            this.staffCount = staffResp.data.staffs.length
          } else if (Array.isArray(staffResp.data.list)) {
            staffList = staffResp.data.list
            this.staffCount = staffResp.data.list.length
          } else if (typeof staffResp.data.total === 'number') {
            this.staffCount = staffResp.data.total
          }
          this.staffs = staffList
          // 随机选取最多5名员工作为首页展示
          this.featuredStaffs = this.pickRandom(staffList, 5)
        }
      } catch (err) {
        console.error('loadData error', err)
      }
    }
    ,
    pickRandom(list, n) {
      if (!Array.isArray(list)) return []
      const copy = list.slice()
      for (let i = copy.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1))
        const tmp = copy[i]
        copy[i] = copy[j]
        copy[j] = tmp
      }
      return copy.slice(0, n)
    }
  }
}

<!-- src/views/Login.vue -->
<template>
  <div class="login-page">

        <el-form ref="loginForm" :model="loginForm" :rules="rules" label-width="0" class="login-form">
          <el-form-item prop="uname">
            <el-input v-model="loginForm.uname" placeholder="用户名">
              <template #prefix>
                <i class="el-icon-user"></i>
              </template>
            </el-input>
          </el-form-item>

          <el-form-item prop="upwd">
            <el-input v-model="loginForm.upwd" placeholder="密码" show-password type="password">
              <template #prefix>
                <i class="el-icon-lock"></i>
              </template>
            </el-input>
          </el-form-item>

          <el-row class="actions" type="flex" justify="space-between" align="middle">
            <el-col :span="14">
              <el-checkbox v-model="remember">记住我</el-checkbox>
            </el-col>
            <el-col :span="10" class="forgot">
              <a @click.prevent class="forgot-link">忘记密码?</a>
            </el-col>
          </el-row>

          <el-form-item>
            <el-button type="primary" @click="login(loginForm)" :loading="loadingbut" class="login-btn" round>{{loadingbuttext}}</el-button>
          </el-form-item>
        </el-form>

        <div class="login-footer">由懒羊羊股份有限公司提供支持</div>
      </el-card>
    </div>
  </div>

<script>
export default {
  name: 'Login',
  data () {
    return {
      loginForm: { uname: '', upwd: '' },
      //验证规则
      rules: {
        uname: [{required: true, message: '请输入用户名', trigger: 'blur'}],
        upwd: [{required: true, message: '请输入密码', trigger: 'blur'}]
      },
      loadingbut: false,
      loadingbuttext: '登录'
    }
  },
  methods: {
    login (loginForm) {
      this.$refs['loginForm'].validate((valid) => {
        if (valid) {
          this.loadingbut = true
          this.loadingbuttext = '登录中...'
          this.$axios
            .post('/login',{
              uname: loginForm.uname,
              upwd: loginForm.upwd
            })
            .then(successResponse => {
              if (successResponse.data === "ok") {
                this.$alert('登录成功', {confirmButtonText: '确定' })
                this.$store.commit('changeLogin',this.loginForm.uname)
                let path = this.$route.query.redirect
                this.$router.replace({path: path === '/' || path === undefined ? '/home': path})
              } else {
                this.$alert('用户名或密码错误！', {confirmButtonText: '确定' })
                this.loadingbut = false;
                this.loadingbuttext = '登录';
              }
            })
            .catch(failResponse => {
              this.$alert(failResponse && failResponse.response ? failResponse.response.status : '请求失败', {confirmButtonText: '确定' })
              this.loadingbut = false
              this.loadingbuttext = '登录'
            })
        } else {
          this.$alert('表单验证失败', {confirmButtonText: '确定' })
          return false;
        }
      })
    },
    cancel(){
      this.$refs['loginForm'].resetFields()
    }
  }
}
</script>

#### 4.2.3 绩效计算逻辑

**实现内容**: 绩效数据通过后端数据库查询获取，ECI（效率贡献指数）由数据库直接计算并返回。

**核心代码**:
```java
// WorkloadDetailService.java
/**
 * 获取项目绩效数据
 * 用于项目绩效展示，包含员工ID、姓名、岗位、工时、任务描述和ECI综合效率
 * @param projectId 项目ID
 * @return 项目绩效数据列表
 */
public List<Map<String, Object>> getProjectPerformance(Integer projectId) {
    return workloadDetailRepository.selectProjectPerformance(projectId);
}
```

**说明**: ECI综合效率由数据库查询直接计算，计算公式为：
`ECI = 工时 × 任务难度 × 质量评分`

系统通过WorkloadController提供RESTful接口，前端调用该接口获取数据后进行展示和排序。

## 五、遇到的问题及解决方案

### 5.1 UI设计问题

**问题**: 不同浏览器之间的样式兼容性问题

**解决方案**:
1. 使用CSS3特性时添加浏览器前缀
2. 使用Flexbox和Grid布局替代传统布局方式
3. 对关键样式进行浏览器兼容性测试
4. 使用Element Plus等成熟组件库，减少兼容性问题

### 5.2 图表性能问题

**问题**: 图表渲染性能较差，特别是在数据量较大时

**解决方案**:
1. 使用ECharts的渐进式渲染功能
2. 对数据进行分页或采样处理
3. 实现图表的懒加载
4. 优化图表配置，减少不必要的动画效果

### 5.3 绩效计算逻辑问题

**问题**: 绩效计算逻辑不够合理，无法准确反映员工的实际绩效

**解决方案**:
1. 与业务部门沟通，了解实际绩效评估需求
2. 设计多维度的绩效评估指标
3. 实现可配置的权重分配机制
4. 定期收集反馈，优化计算逻辑
