## 二、各可视化功能内在逻辑说明 

### 1. 部门工作量柱状图（Department.vue） 

**内在逻辑：** 
- **数据来源**：通过Axios调用后端`getWorkloadStatistics`接口获取各部门工作量数据 
- **图表初始化**：在`mounted`生命周期中调用`initChart`方法，使用`nextTick`确保DOM渲染完成 
- **数据处理**：根据`chartType`（总工作量/本月工作量）筛选对应数据 
- **图表配置**：设置柱状图颜色、坐标轴标签、提示框样式 
- **交互处理**：点击图表类型切换按钮时，重新加载数据并渲染图表 

**核心代码逻辑：** 
```javascript 
// 图表初始化逻辑 
initChart() { 
  this.$nextTick(() => { 
    const chartDom = document.getElementById('workloadChart'); 
    if (chartDom) { 
      this.chart = echarts.init(chartDom); 
      this.loadWorkloadData(); // 加载数据并渲染 
    } 
  }); 
} 

// 数据加载逻辑 
async loadWorkloadData() { 
  try { 
    const response = await this.$http.get('/api/workload/statistics', { 
      params: { type: this.chartType } 
    }); 
    this.chartData = response.data; 
    this.renderChart(); // 渲染图表 
  } catch (error) { 
    this.$message.error('数据加载失败'); 
  } 
} 
```

### 4. 项目任务甘特图（TaskProject.vue） 

**内在逻辑：** 
- **数据来源**：获取项目任务数据，包含任务名称、开始/结束时间、总工时 
- **数据处理**：按任务描述分组合并相同任务数据 
- **自定义渲染**：使用ECharts自定义系列绘制任务条 
- **交互功能**：支持水平/垂直缩放、时间轴拖动、任务详情提示 

**核心渲染逻辑：** 
```javascript 
renderItem: function(params, api) { 
  // 计算任务条位置和尺寸 
  const categoryIndex = api.value(0); 
  const start = api.coord([api.value(1), categoryIndex]); 
  const end = api.coord([api.value(2), categoryIndex]); 
  const height = api.size([0, 1])[1] * 0.7; 
  
  // 返回任务条矩形配置 
  return { 
    type: 'rect', 
    shape: { 
      x: start[0], 
      y: start[1] - height / 2, 
      width: Math.max(end[0] - start[0], 2), // 确保最小宽度 
      height: height 
    }, 
    style: api.style() 
  }; 
} 
``` 

### 5. 质量趋势图（ImageAnalyze.vue）

**内在逻辑：**
- **数据来源**：通过`/getWorkloadStatsByStaffId`接口获取质量分数历史数据（`quality_scores_str`）
- **数据处理**：将字符串化的逗号分隔数据转换为数值数组，并将0-1范围标准化为0-100百分比
- **时间轴处理**：根据数据量动态生成日期标签，确保时间从左到右显示最早到最新数据
- **动态标签**：根据数据量自动调整标签密度（长期数据每7天显示一个标签）
- **图表渲染**：使用ECharts折线图展示质量分数变化趋势

**核心代码逻辑：**
```javascript
// 数据解析逻辑
const parseStringToArray = (str) => {
  if (!str) return [];
  return str.split(',').map(v => parseFloat(v)).filter(v => !isNaN(v));
};

// 时间标签生成逻辑
const dateLabels = [];
const today = new Date();
const dataPoints = qualityScores.length;
for (let i = 0; i < dataPoints; i++) {
  const date = new Date(today);
  const daysDiff = dataPoints - 1 - i;
  date.setDate(today.getDate() - daysDiff);
  const labelFormat = `${date.getMonth() + 1}/${date.getDate()}`;
  const showLabel = dataPoints > 30 ? i % 7 === 0 : dataPoints > 15 ? i % 3 === 0 : true;
  dateLabels.push(showLabel ? labelFormat : '');
}
```

  - 更新模板使用`pointsData`替代原`analyzeResult`数据来源

- **核心代码**：

## 四、遇到的问题及解决过程 

### 1. 界面功能问题 

**问题**：部门管理界面中平均质量分列多余，操作栏目下的编辑和详情按钮无法打开。 

**解决过程**： 
1. 分析`Department.vue`文件，确认平均质量分列为冗余功能 
2. 删除该列的模板代码和相关数据处理逻辑 
3. 检查`handleEdit`方法，发现缺少实现代码 
4. 补充编辑和详情按钮的点击事件处理逻辑，确保正确跳转到对应页面 

### 2. SQL数据库问题 

**问题1**：增加工作量数据时，`start_date`和`end_date`字段爆红。 

**解决过程**： 
1. 分析数据库表结构，发现实际表中没有`start_date`和`end_date`字段 
2. 修改SQL文件，将INSERT语句中的这两个字段删除 
3. 更新前端数据结构，确保与后端表结构一致 

**问题2**：运行SQL文件时出现`1062-Duplicate entry '6' for key primary`错误。 

**解决过程**： 
1. 确认错误原因：SQL文件中使用的ID值与数据库中现有数据冲突 
2. 修改SQL文件，将所有ID范围改为100-119（高于现有数据ID） 
3. 重新运行SQL文件，避免主键冲突 

**问题3**：数据库报错`Unknown column 'start_date' in 'field list'`和`Column 'work_date' cannot be null`。 

**解决过程**： 
1. 检查`WorkloadDetailMapper.xml`文件，发现引用了不存在的`start_date`列 
2. 修改SQL映射文件，将`#{startDate}`改为`#{workDate}` 
3. 确保前端传递的参数与后端映射一致 

### 3. 图表渲染问题 

**问题**：图表初始化时DOM元素未加载完成，导致图表渲染失败。 

**解决过程**： 
1. 使用Vue的`nextTick`方法确保DOM渲染完成后再初始化图表 
2. 添加条件渲染（`v-if="showChart"`）确保数据加载完成后显示图表 
3. 实现图表实例的销毁与重建机制，避免内存泄漏
